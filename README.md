# KIDS Gaming Hub

Crie um painel com o nome KIDS, na coloração vermelho e preto e que nesse painel contem diversas areas de jogos, uma dessas areas é o cs2 na qual terá opções para alterar dpi do mouse, alterar sensibilidade dentro do jogo, alterar mira ( com diversas opções de miras de pro player pré setadas ), setar configurações de proplayer ( Vai ter diversas configurações como por exemplo: fallen, zayow, molodoy etc.. após clicar em setar config, será setado toda a confugração que o proplayer usa ( dpi, sensi, qualidade de video, mira, textura etc... ) coloque configuração para otmizar o teclado e mouse para que tenha uma melhor jogabilidade e desempenho em partidas. faça um painel completo e 100% funcional, se possivel coloque um tema de notas de dinheiro, mafia etc..
